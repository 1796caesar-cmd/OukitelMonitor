ВИПРАВЛЕННЯ — У OUKITEL MONITOR НЕМАЄ КНОПКИ ОНОВЛЕНЬ

ПРИЧИНА:
У репозиторії вже є файл scripts/update_22_inapp.py, але поточний
.github/workflows/build-apk.yml продовжує збирати версію 1.10 (assembleDebug).
GitHub Actions не запускає скрипти підпису та перевірки оновлень.

ВАЖЛИВО: треба ЗАМІНИТИ вміст вже існуючого файлу:
.github/workflows/build-apk.yml
Не достатньо просто додати папку .github через Upload files —
переконайтеся, що старий файл справді перезаписано!

СПОСІБ:
1) Відкрийте https://github.com/1796caesar-cmd/OukitelMonitor
2) Натисніть клавішу . (відкриється github.dev)
3) У лівій колонці відкрийте .github/workflows/build-apk.yml
4) Відкрийте завантажений build-apk.yml у Блокноті, виділіть усе Ctrl+A,
   скопіюйте Ctrl+C. У github.dev у відкритому старому файлі
   виділіть все Ctrl+A та вставте Ctrl+V.
5) У розділі Source Control (іконка з гілкою) зробіть Commit & Push.
6) Перевірте Actions: мають бути кроки
   "Add in-app GitHub Releases updater for Android 2.2",
   "Build signed release APK", "Publish signed APK in GitHub Releases".
7) Завантажте OukitelMonitor-2.2.apk і встановіть.

Не завантажуйте в репозиторій .jks чи секрети!
Секрети мають бути в Settings → Secrets and variables → Actions.

ПРИМІТКА: Якщо раніше стояв APK, підписаний debug-ключем,
Android не встановить release APK поверх нього. Такі ключі не сумісні.
Під час видалення додатка втрачаються локальні дані й налаштування.
Наступні оновлення, підписані тим самим постійним ключем, оновлюються поверх.
