# OukitelMonitor

Android app prototype for Oukitel P1000E Plus.

## Build

Open GitHub Actions -> Build Android APK -> latest successful run -> Artifacts -> OukitelMonitor-debug-apk.

## Current status

This first APK shows a placeholder screen only. It **does not yet connect to Wonderfree**, display live readings, or send notifications. These features need an authenticated, tested integration. Do not publish account credentials or tokens in this public repository.
