OukitelMonitor 1.10 — прибрати плитку «Вихідна напруга»

Пакет встановлюється поверх проєкту, у якому вже є файли версії 1.9.

1) Відкрий GitHub-редактор репозиторію OukitelMonitor (клавіша «.»).
2) Перетягни папки scripts і .github із цього архіву в корінь репозиторію.
   ПОЄДНУЙ папки, а не видаляй старі. Файл build-apk.yml треба замінити.
3) Source Control → повідомлення «Remove voltage panel 1.10» → Commit & Push.
4) GitHub → Actions → найновіша збірка → Artifacts → OukitelMonitor-1.10-APK.

Зміни: лише прибрано видимий блок «Вихідна напруга» і код його оновлення.
Кільце заряду, метрики, графік, фонова служба і сповіщення лишаються.

Збірка APK має бути підтверджена в GitHub Actions після завантаження змін.
