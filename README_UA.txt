OUKITEL MONITOR 1.9 — ОНОВЛЕННЯ
================================

Цей пакет містить УСІ зміни версій 1.7, 1.8 і 1.9. Окремо 1.7/1.8 встановлювати НЕ потрібно.

Версія 1.7
- Замість «Режим роботи» показуємо фактичну вихідну напругу станції, якщо вона доступна через API (інакше — «—»).
- Графік заряду з'єднує всі наявні виміряні точки незалежно від часу між ними.

Версія 1.8
- Автоматичне повторне підключення Wonderfree, коли токен завершується.
- Облікові дані для автовходу зберігаються локально, зашифровано Android Keystore.
- Для ввімкнення автовходу після встановлення потрібно ОДИН РАЗ вийти й повторно ввійти у Wonderfree через додаток.

Версія 1.9
- Після нового успішного зчитування заряду на головному екрані негайно оновлюємо ТОЙ САМИЙ постійний запис у шторці.
- Якщо екран відкритий і має нещодавні актуальні дані, фонова служба не перезаписує шторку старішим результатом паралельного опитування.
- Коли додаток згорнутий, фонова служба продовжує звичайну роботу за вибраним інтервалом.
- Правила повідомлень про заряд, зникнення мережі й початок заряджання не змінюються.

УВАГА: Якщо Android обмежує фонову роботу, оновлення шторки у фоні може затримуватись.
Коли дані на екрані справді оновлюються, у шторці відсоток має змінюватися одразу.

ЯК ЗАВАНТАЖИТИ В GITHUB
1. Розпакуй архів.
2. Відкрий https://github.com/1796caesar-cmd/OukitelMonitor та натисни клавішу крапки (.).
3. Скопіюй папки scripts і .github У КОРІНЬ репозиторію з ОБ'ЄДНАННЯМ наявних папок.
   Старі файли проєкту не видаляй. Файл .github/workflows/build-apk.yml заміни на цей.
4. Зроби Commit & Push.
5. Відкрий GitHub Actions → останній Build Android APK → Artifacts → OukitelMonitor-1.9-APK.
6. APK встановлюй поверх попередньої версії за умови збігу підпису.

Під час збірки застосовуються скрипти 1.5 → 1.6 → 1.7 → 1.8 → 1.9.
У цьому архіві є лише нові/змінені скрипти та workflow; старі 1.5/1.6 вже є в репозиторії.

ПЕРЕВІРКА

Повний Android APK тут не компілювався, на реальній станції поведінка не перевірялась.
