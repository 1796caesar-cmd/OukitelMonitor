OUKITEL MONITOR ДЛЯ WINDOWS — ПЕРША ТЕСТОВА ВЕРСІЯ
====================================================

ЩО ВМІЄ:
- Відсоток заряду станції прямо на значку біля годинника Windows.
- Подвійне клацання по значку або пункт «Відкрити» відкриває вікно.
- Кнопка X ховає вікно, програма продовжує працювати.
- Вхід у Wonderfree з автоматичним повторним входом за потреби.
- Заряд, вхідна/вихідна потужність, температура, час роботи.
- Графік заряду за 24 години / 7 днів / 30 днів, з'єднує всі отримані точки.
- Опитування кожні 30 секунд / 1 / 3 / 5 / 10 хвилин, ручне оновлення.
- Опція запуску разом із Windows.
- За бажанням — сповіщення при заряді 5% і 100%.
- Пароль у зашифрованому файлі Windows DPAPI, тільки на цьому комп'ютері.

ЯК ОТРИМАТИ .EXE БЕЗ ВСТАНОВЛЕННЯ PYTHON НА ПК:
1. Розпакуй архів.
2. Відкрий https://github.com/1796caesar-cmd/OukitelMonitor
3. Натисни крапку (.) для github.dev.
4. Скопіюй папку windows_monitor та файл
   .github/workflows/build-windows-monitor.yml в однойменні шляхи репозиторію.
   Старі Android-файли НЕ чіпай.
5. Зроби Commit & Push.
6. Відкрий https://github.com/1796caesar-cmd/OukitelMonitor/actions
7. Знайди «Build Oukitel Monitor Windows», дочекайся зеленої галочки.
8. В Artifacts з'являться OukitelMonitor-Windows-x64 та
   OukitelMonitor-Windows-x86 (для 32-бітної Windows).
9. Завантаж потрібний архів, розпакуй EXE, запусти.

ПЕРШИЙ ЗАПУСК:
- Увійди в обліковий запис Wonderfree (регіон зазвичай EU).
- Якщо є кілька станцій, відкрий Налаштування і вибери потрібну.
- У Налаштуваннях увімкни «Запускати разом із Windows».
- Щоб заряд завжди був ВИДИМИЙ біля годинника, перетягни значок
  Oukitel із меню прихованих значків (стрілка ^) в панель біля годинника.
  Цим керує Windows — сама програма не може обійти це налаштування.

ВАЖЛИВО:
- Це перша тестова Windows-версія, код перевірено на синтаксис,
  але не перевірено на твоїй реальній станції чи на Windows.
- Значок показує останній ОТРИМАНИЙ відсоток; коли дані застаріли,
  фон значка стає сірим і підказка повідомляє про неактуальні дані.
- Без інтернету / Wonderfree нових значень не буде.
- Поки що EXE без цифрового підпису, тому Windows SmartScreen може
  попереджати про невідомого розробника; встановлюй лише з власної збірки.
- 32-бітний EXE призначений для 32- та 64-бітної Windows,
  64-бітний — лише для 64-бітної Windows.
- Показник напруги не включено: API не підтвердив його на P1000E Plus.
- Немає функцій керування живленням станції — лише моніторинг.

Зміни Windows-додатка не впливають на Android Oukitel Monitor.
