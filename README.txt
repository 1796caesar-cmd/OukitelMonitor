OUKITEL MONITOR ДЛЯ WINDOWS — ОНОВЛЕННЯ
====================================

Зміни:
- Окремі сповіщення для зниження заряду (поріг 1–100%) та досягнення заряду (поріг 1–100%).
- Кожне сповіщення можна вимкнути окремо.
- За замовчуванням залишаються 5% і 100% (попередні налаштування не стираються).
- Сповіщення спрацьовують тільки при перетині заданого порога.
- Значок у системному треї: біле контурне коло, біла цифра заряду, прозорий фон без заливки.

УСТАНОВЛЕННЯ ОНОВЛЕННЯ
1. Розпакуйте ZIP.
2. Додайте папку windows_monitor до вашого репозиторію OukitelMonitor в GitHub.
3. Оновіть файл .github/workflows/build-windows-monitor.yml з архіву.
4. Зробіть Commit & Push у main.
5. Відкрийте GitHub → Actions → Build Oukitel Monitor Windows.
6. Після успішної збірки завантажте потрібний EXE з Artifacts (x64 або x86).
7. Закрийте стару програму через її меню в треї та запустіть новий EXE.

ТЕХНІЧНО
windows_monitor/apply_update.py автоматично змінює наявний app.py під час збірки.
Сам app.py вручну редагувати не потрібно. Android-код не змінюється.

Пакет містить нові модулі alert_rules.py і tray_style.py, тести та workflow.
Справжню збірку GitHub Actions і підключення до станції потрібно перевірити після завантаження.
