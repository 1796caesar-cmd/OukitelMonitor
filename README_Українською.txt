OUKITEL MONITOR — WINDOWS 1.2
Оновлення: кілька сповіщень, великий текстовий значок заряду, нові інтервали

ЩО ДОДАНО
1. Декілька незалежних сповіщень «Нижче X%» (наприклад, 90, 70, 50, 30, 15%).
2. Декілька незалежних сповіщень «Досягнуто X%» (наприклад, 95%, 100%).
3. Для кожного порога є перемикач увімкнення, поле відсотка та видалення.
4. Значок у треї без рамки, кола та заливки — тільки великий білий відсоток «90%».
5. Нові інтервали опитування: 15 хвилин, 30 хвилин, 1 година.
6. Старі налаштування порогів 1.1 автоматично перетворюються в один пункт відповідного списку.

ЯК ПЕРЕЗІБРАТИ
1. Розпакуйте цей ZIP.
2. На https://github.com/1796caesar-cmd/OukitelMonitor відкрийте редактор клавішею «.»
3. У відповідні папки репозиторію скопіюйте файли з архіву:
   windows_monitor/app.py
   windows_monitor/alert_rules.py
   windows_monitor/tray_style.py
   windows_monitor/tests/test_alert_rules.py
   .github/workflows/build-windows-monitor.yml
4. Замініть однойменні файли, зробіть Commit & Push.
5. Відкрийте GitHub Actions > Build Oukitel Monitor Windows.
6. Коли збірка стане зеленою, у розділі Artifacts завантажте x64 або x86.
7. Закрийте старий Oukitel Monitor через меню значка біля годинника,
   потім запустіть новий EXE. Збережені налаштування та логін залишаються на ПК.

ВАЖЛИВО
- Раніше workflow запускав apply_update.py. У цьому архіві вже повністю
  оновлений app.py, тому НОВИЙ workflow НЕ запускає старий патч.
  Обов'язково замініть також .github/workflows/build-windows-monitor.yml.
- Якщо за час між двома вимірюваннями заряд перетнув кілька порогів, кожен
  увімкнений поріг породжує своє сповіщення. Сповіщення приходять лише
  після нового фактичного вимірювання.
- Windows визначає розмір значка трея; програма використовує максимальну
  площу стандартного значка, але не може збільшити системну комірку.
- Це вихідні файли для GitHub Actions, не готовий EXE. Роботу на реальному ПК
  і доступ Wonderfree потрібно перевірити після збірки.

Програма для Android не змінюється.
